Data Analyzer and Transformer Program

1. Project Description

The Data Analyzer and Transformer Program is a menu-driven Python application that allows users to input, analyze, filter, and sort numerical data.

The program supports both 1D and 2D lists and provides various operations using Python concepts such as functions, recursion, lambda functions, built-in functions, global variables, and multiple return values.

2. Features

- Input Data: Accept numerical data in the form of a 1D or 2D list.
- Data Summary: Display the total number of elements, minimum value, maximum value, sum, and average.
- Factorial Calculation: Calculate the factorial of a number using recursion.
- Filter Data: Filter values greater than or equal to a specified threshold using a lambda function.
- Sort Data: Sort 1D and 2D data in ascending or descending order.
- Dataset Statistics: Calculate and display multiple statistical values using "*args" and "**kwargs".
- Global Summary: Store dataset statistics in a global dictionary.
- Display 2D Data: Display two-dimensional data in a structured tabular format.

5. How to Run the Program

1. Install Python on your computer.
2. Open a Python-supported editor, such as IDLE, VS Code, or PyCharm.
3. Create a new Python file.
4. Copy the program code into the file.
5. Save the file as "data_analyzer.py".
6. Run the Python file.
7. Select an option from the main menu and follow the instructions.
